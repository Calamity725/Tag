# Tag
A little game where an enemy chases you around a grid, you can place walls to block him, if he tags you, you lose, you cannot move diagonally and you must place a wall on an adjacent square
Using the Modulo operator and floor division I was able to make the grid expand to any size, and easily check for the coordinates of the character, the walls, and the enemy. using this same logic I was also able to prevent the enemy from looping or phasing through your walls, and made it so he has to go around the walls
